# 智能知识点笔记 · 用户手册

适用版本：1.0.0

本手册面向最终用户，介绍安装、日常使用、数据备份与常见问题。开发与架构说明见 [README](../README.md)，发布与验证信息见 [v1.0.0 发布说明](./%E5%8F%91%E5%B8%83%E8%AF%B4%E6%98%8E-v1.0.0.md)。

## 1\. 应用简介

智能知识点笔记是一款完全本地运行的桌面知识管理工具：

```text
课程 → 多级知识点 → Markdown 笔记 → 标签 / 知识点关联 → 知识图谱

```

所有课程、知识点、笔记、标签与关联都保存在本机 SQLite 数据库中，应用不依赖网络，也不会上传任何内容。

## 2\. 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809 及以上 / Windows 11（x64） |
| 运行时 | Microsoft Edge WebView2 Runtime（安装包已内置引导安装程序） |
| 磁盘空间 | 安装约 10 MB，数据随笔记数量增长 |
| 权限 | NSIS 安装包为当前用户安装，无需管理员；MSI 安装需要管理员 |

## 3\. 安装与卸载

### 3.1 使用 NSIS 安装包（推荐）

1.  双击 `智能知识点笔记_1.0.0_x64-setup.exe`；
2.  按向导选择安装语言与安装位置（默认 `%LOCALAPPDATA%\智能知识点笔记`）；
3.  安装完成后从开始菜单或桌面快捷方式启动。

安装过程不需要管理员权限；如果系统缺少 WebView2，安装程序会先完成运行时安装。

静默安装（适合批量部署）：

```powershell
"智能知识点笔记_1.0.0_x64-setup.exe" /S

```

### 3.2 使用 MSI 安装包

`智能知识点笔记_1.0.0_x64_zh-CN.msi` 面向域 / 企业分发，安装范围为所有用户（`ALLUSERS=1`），需要以管理员身份运行。普通个人使用建议选择 NSIS 安装包。

```powershell
msiexec /i "智能知识点笔记_1.0.0_x64_zh-CN.msi"

```

### 3.3 卸载

任选一种方式：

-   Windows「设置 → 应用 → 已安装的应用 → 智能知识点笔记 → 卸载」；
-   开始菜单中的应用目录 → 卸载；
-   运行安装目录下的 `uninstall.exe`（NSIS 安装包）。

卸载只删除程序文件与快捷方式，**不会删除数据库**。重新安装后原有课程、知识点与笔记会继续显示。

## 4\. 首次启动与界面概览

启动后进入首页。窗口为无边框设计，由应用内标题栏承担系统标题栏职责：

-   拖动标题栏空白区域移动窗口，双击最大化 / 还原；
-   右上角提供最小化、最大化 / 还原与关闭按钮；
-   窗口四边与四角可拖动缩放。

左侧导航栏包含：

| 入口 | 用途 |
| --- | --- |
| 首页 | 数据统计、最近编辑的笔记、最近创建的知识点 |
| 课程管理 | 课程增删改查与课程详情 |
| 知识点管理 | 按课程维护多级知识点树 |
| 笔记 | 沉浸式笔记工作区（编辑 / 分屏 / 预览） |
| 笔记库 | 跨课程检索全部笔记 |
| 标签管理 | 标签维护与按标签查看笔记 |
| 知识关联 | 知识点之间的语义关联与建议 |
| 知识图谱 | 可视化课程知识结构 |
| 设置 | 外观、数据库信息、备份与恢复 |

顶栏右侧提供全局搜索入口；侧边栏可折叠，为内容区让出空间。

## 5\. 快速上手

1.  **创建课程**：进入「课程管理 → 新建课程」，填写名称（必填，≤60 字）与描述（≤500 字）；
2.  **建立知识点**：进入「知识点管理」，选择课程后新建顶层知识点，或使用行内 `+` 在某个知识点下新建子知识点；
3.  **写笔记**：在知识点详情或左侧目录点击「在笔记中打开」，在编辑区编写 Markdown，内容会自动保存；
4.  **加标签**：在笔记右侧面板输入标签名称并添加，之后可在「标签管理」按标签筛选笔记；
5.  **建关联**：在「知识关联」页把两个知识点连接起来（前置 / 相关 / 包含 / 对比 / 延伸），也可以接受系统给出的关联建议；
6.  **看图谱**：进入「知识图谱」，选择课程即可查看知识点层级与语义关联，点击节点查看详情。

## 6\. 功能详解

### 6.1 课程管理

-   课程列表展示知识点数、笔记数与最近更新时间；
-   新建与编辑共用同一弹窗，后端会校验名称非空、长度限制并阻止同名课程；
-   删除课程需要二次确认，确认框会说明该课程下的知识点、笔记与关联将级联删除；
-   课程详情页展示课程简介、知识点结构，并提供笔记工作区与知识图谱入口。

### 6.2 知识点管理

-   左栏切换课程，中栏展示多级知识点树，右侧为选中知识点的详情；
-   新建知识点时可指定父知识点，支持任意层级；
-   层级调整：「降为子级」成为同级上一个知识点的子节点，「提升一级」与父节点同级，也可在编辑弹窗中直接修改父节点；
-   删除知识点会连同全部后代知识点、笔记及相关关联一起删除，确认框会给出准确数量；
-   「迁移课程」把知识点连同子树移动到另一门课程，根节点成为目标课程的顶层知识点。

### 6.3 笔记工作区

`笔记` 页面为三栏布局：

-   **左栏**：课程与知识点目录，可新建课程 / 知识点，可拖动边缘调整宽度（200–380px），也可整体折叠；
-   **中栏**：Markdown 编辑器，支持编辑 / 分屏 / 预览三种模式；分屏在窗口较窄时自动上下排列；
-   **右栏**：所属知识点、字数、更新时间、笔记标签、相关知识点与关联建议，可隐藏。

编辑行为：

-   停止输入约 800ms 后自动保存，`Ctrl + S` 立即保存；
-   保存状态会显示为未保存 / 保存中 / 已保存 / 保存失败；
-   切换知识点前会先保存当前草稿；关闭窗口前也会落盘；
-   标题与正文都为空时不会创建空笔记；
-   删除笔记需要二次确认。

Markdown 支持标题、列表、引用、代码块、表格等常用语法；为保证安全，内联 HTML 不会被执行，外部链接会以新窗口打开并附带安全属性。

工具栏提供：

-   **导入 Markdown**：选择本地 `.md` 文件，预览正文、修改标题、选择目标知识点；目标知识点已有笔记时会提示覆盖；
-   **导出 Markdown**：先保存草稿，再通过系统保存对话框导出为 `.md` 文件；正文缺少一级标题时会自动补上笔记标题。

导入规则：文件首行的 `# 一级标题` 作为笔记标题并从正文移除；没有一级标题时使用文件名；仅支持 UTF-8 文本，文件上限 2 MB。

### 6.4 笔记库

-   列出全部笔记，显示标题、摘要、所属课程 / 知识点、标签、字数与更新时间；
-   关键字搜索同时匹配标题与正文，标题命中的结果排在前面；
-   标签筛选条可与关键字组合，筛选条件可通过链接（`?tag=`）直接带入；
-   点击笔记直接打开到笔记工作区；
-   支持导入 Markdown 与导出 `.md`。

### 6.5 标签管理

-   左侧标签列表显示每个标签的笔记数量，可按名称搜索；
-   新建同名标签会复用已有记录，重命名时同名会被拦截；
-   删除标签需要二次确认，只解除标签与笔记的关联，不会删除笔记；
-   右侧可直接打开该标签下的笔记，或跳转笔记库并带上筛选条件。

### 6.6 知识关联

-   左侧按课程筛选知识点并显示关联数量，支持按名称 / 描述搜索；
-   中间展示当前知识点的关联：类型、两端知识点、描述、课程路径，可编辑类型与描述或删除；
-   「新建关联」支持跨课程选择源 / 目标知识点；系统会阻止自关联、同类型重复关联以及无向类型的反向重复；
-   「关联类型」弹窗维护类型字典（前置、相关、包含、对比、延伸），可改名、换色、调整有向性或新增自定义类型；内置与被使用的类型不允许删除；
-   右侧关联建议仅比较同一课程内的知识点：融合名称、描述与笔记内容的本地相似度，展示得分与共同关键词理由；接受后写入正式关联，忽略后不再重复推荐。

### 6.7 知识图谱

-   节点来自当前课程的知识点树，父子层级为灰色虚线，语义关联按类型着色，有向关系带箭头；
-   节点可拖动，画布支持滚轮缩放、空白拖动平移、自动适配视图；
-   顶部筛选：课程、层级上限（全部 / 仅顶层 / 前 N 层）、关联类型多选、层级连线与关系标签开关；
-   布局可在层次树与关系网络（力导向）之间切换，「重新布局」恢复自动排布；
-   点击节点在右侧查看路径、统计、描述与关联列表，并可跳转到笔记、知识点管理或知识关联页。

### 6.8 首页与全局搜索

首页展示课程、知识点、笔记、标签与关联数量，以及最近编辑的笔记和最近创建的知识点，点击卡片或条目可进入对应页面。

全局搜索：点击顶栏「搜索」或按 `Ctrl + K`（macOS 为 `Cmd + K`），输入关键字后检索课程、知识点、笔记、标签与知识关联；结果按类型分组，支持 `↑` / `↓` 移动、`Enter` 打开、`Esc` 关闭。

### 6.9 外观主题

在「设置 → 外观」中切换：

-   **自动**：跟随 Windows 的浅色 / 深色设置并实时响应；
-   **日间**：始终使用浅色主题；
-   **夜间**：始终使用深色主题。

选择会保存在本机，重启后保持。

### 6.10 数据备份与恢复

「设置 → 数据与备份」显示数据库文件路径、大小、最后修改时间、SQLite 版本与各表记录数，并提供：

-   **备份数据库**：选择保存位置，生成一致的 `.db` 副本；
-   **恢复数据库**：选择 `.db / .sqlite / .sqlite3` 文件；系统会先校验 SQLite 文件头、`PRAGMA quick_check` 与业务表结构，然后在数据库同目录生成 `knowledge_graph-before-restore-<时间>.db` 安全副本，再替换并重新加载应用；
-   **在文件夹中显示**：打开数据库所在目录。

恢复失败时会尽量回滚到安全副本，不会破坏原数据库。

## 8\. 数据存储与迁移

| 内容 | 位置 |
| --- | --- |
| 数据库 | `%APPDATA%\com.gaotiankai.knowledge-graph-notes\knowledge_graph.db` |
| 恢复前安全副本 | 同目录下的 `knowledge_graph-before-restore-*.db` |
| 程序文件（NSIS） | `%LOCALAPPDATA%\智能知识点笔记` |

迁移到另一台电脑：

1.  在原电脑「设置 → 数据与备份」中备份数据库；
2.  在新电脑安装并启动一次应用，关闭应用；
3.  在新电脑「设置 → 数据与备份」中恢复该备份文件，应用会自动重新加载。

也可以直接复制 `knowledge_graph.db` 覆盖新电脑上的同名文件（请先关闭应用）。

## 9\. 常见问题

**安装时提示需要管理员权限？**  
MSI 安装包为所有用户安装，必须提权；请改用 NSIS 安装包，或右键 MSI 选择「以管理员身份运行」。

**启动后白屏或提示缺少 WebView2？**  
确认系统已安装 Microsoft Edge WebView2 Runtime。安装包内置引导程序，也可以从微软官网手动安装后重启应用。

**卸载后数据会丢失吗？**  
不会。卸载只删除程序，数据库保留在 `%APPDATA%` 下；如需彻底清除，请手动删除该目录。

**笔记内容会自动保存吗？**  
会。停止输入约 800ms 自动保存，切换知识点、导出或关闭窗口前也会先保存；状态栏会显示保存结果。

**关联建议为什么没有出现？**  
建议只比较同一课程内的知识点，并会排除已有正式关联、已接受或已拒绝的知识点对；相似度低于阈值时不会推荐。补充知识点描述与笔记内容通常会提高推荐质量。

**可以离线使用吗？**  
可以。除安装阶段可能需要 WebView2 外，应用运行、关联建议与图谱布局全部在本地完成。

**支持哪些笔记格式？**  
Markdown（UTF-8）。导入文件上限 2 MB；其他编码请先转换为 UTF-8。
