## 3. 安装说明

### 3.1 推荐：NSIS 安装包

- 当前用户安装，默认目录 `%LOCALAPPDATA%\智能知识点笔记`，无需管理员权限；
- 安装界面支持简体中文 / 英文，可在安装时选择；
- 自动创建开始菜单与桌面快捷方式；
- 内置 WebView2 引导安装程序。

静默安装：

```powershell
"智能知识点笔记_1.0.0_x64-setup.exe" /S
```

### 3.2 MSI 安装包

- 面向域 / 企业分发，`ALLUSERS=1`，安装需要管理员权限；
- 固定升级码 `fea5ef73-e38d-45c7-a3b3-2ae24dd22237`，支持后续版本升级；
- 语言：简体中文、英文。

```powershell
msiexec /i "智能知识点笔记_1.0.0_x64_zh-CN.msi"
```

### 3.3 系统要求

- Windows 10 1809 及以上 / Windows 11（x64）；
- Microsoft Edge WebView2 Runtime；
- 安装约 10 MB 磁盘空间。

### 3.4 数据位置与升级

- 数据库：`%APPDATA%\com.gaotiankai.knowledge-graph-notes\knowledge_graph.db`；
- 程序与数据分离，卸载或覆盖安装不会删除数据；
- 从开发版升级时，只要应用标识不变，数据库会继续沿用；应用启动时会自动补齐数据库迁移。

## 4. 功能总览

v1.0.0 包含完整的个人知识管理闭环：

- **课程管理**：课程增删改查、详情、级联删除提示；
- **知识点管理**：多级知识点树、详情面板、层级调整、课程迁移、子树级联删除；
- **Markdown 笔记**：编辑 / 分屏 / 预览、自动保存、笔记库检索、Markdown 导入导出；
- **标签**：标签维护、笔记标签关联、按标签筛选与搜索；
- **知识关联**：五种内置关联类型与自定义类型、自关联 / 重复关联校验、本地关联建议（接受 / 忽略）；
- **知识图谱**：Vue Flow 画布、层级与语义连线、拖拽缩放平移、层级 / 类型筛选、层次布局与力导向布局；
- **首页与辅助**：数量统计、最近编辑 / 创建、全局搜索（`Ctrl + K`）、数据库备份与恢复；
- **外观**：自动 / 日间 / 夜间三档主题，偏好持久化；
- **数据安全**：SQLite 参数化查询、外键与级联约束、备份校验、恢复前安全副本。

## 6. 已知限制

1. **MSI 需要管理员权限**：Tauri 的 WiX 安装包固定 `ALLUSERS=1`，普通用户请使用 NSIS 安装包；
2. **安装包未进行代码签名**：首次运行时 Windows SmartScreen 可能提示未知发布者，确认来源后可继续；
3. **未启用自动更新**：新版本需要手动下载安装包覆盖安装，数据会保留；
4. **仅提供 Windows x64 产物**：图标资源包含 macOS / Android / iOS 规格，但本次未构建其它平台安装包；
5. **知识图谱规模**：布局在浏览器主线程计算，知识点规模很大时布局耗时会增加，可切换层次布局或减少展示层级。
